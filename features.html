📋 homeクラ 機能一覧

配信ポータル（index.html）と管理画面（admin）に組み込まれている機能の一覧です。

🏠 index.html ― 配信ポータル（表示系）
🔴
LIVE 中メンバー表示
index
YouTube Live APIでリアルタイムに配信中チャンネルを検出し、サムネ付きカードで最上部に表示。緑ボーダー＋LIVEバッジで強調。
YouTube API
🕒
配信予定（Upcoming）表示
index
liveStreamingDetailsの scheduledStartTime を取得し、日時をフォーマットして「配信予定のメンバー」セクションに表示。
YouTube API
🎬
24時間以内の新着動画
index
公開から24時間以内の動画を「新着」として検出し、NEWバッジ付きカードで表示。
YouTube API
👥
メンバー一覧（リスト表示）
index
全メンバーをMinecraftアバター＋SNSリンクボタン付きでグリッド表示。YouTube / X / Twitch / TikTok / Instagram / Discord に対応。
UI
🎲
ルーレットボタン
index
ヘッダー左に配置。外部の旬茶作ルーレットページ（roulette.html）を新しいタブで開くリンク。
UI
🔄 index.html ― 更新・キャッシュ・節約
💾
10分キャッシュ
index
YouTube APIレスポンスをlocalStorageに保存し、10分間は再取得せずキャッシュを描画。API quota消費を大幅に削減。取得失敗時はキャッシュにフォールバック。
キャッシュlocalStorage
⏱️
カウントダウンタイマー＋プログレスバー
index
次回更新まで「MM:SS」形式でカウントダウン表示。上部の緑バーも残り時間に連動して縮小。タイマー切れは画面リロードなしでAPI再取得。
UI
🛡️
更新ボタン連打防止（disabled）
index
「更新」ボタン押下後、15秒間 disabled にしてカウントダウン表示（「更新 (14s)」…）。キャッシュを消去してAPI再取得するため、連打によるquota浪費を防ぐ。
連打防止UI
🚧
F5連打ガード
index
beforeunloadでリロード時刻を記録し、20秒以内の再読み込みはAPIを呼ばずキャッシュを強制使用。F5連打によるAPI quota浪費を防止。
F5対策キャッシュ
🔔 index.html ― 通知・予約
🔔
配信開始 通知予約
index
Upcoming動画に「🔔 通知予約」ボタンを表示。予約するとブラウザ通知の許可を求め、開始時刻に「配信開始！」をプッシュ通知。予約状態はlocalStorageに保存。
通知APIlocalStorage
✅
通知状態の永続化
index
通知済みかどうかを `notified` フラグでlocalStorageに管理。30秒ごとにポーリングして重複通知を防ぐ。
localStorage
📱 index.html ― スマホ連携
📱
QRコード モーダル
index
ヘッダーの「QR」ボタンを押すと現在URLのQRコードをモーダル表示。スマホカメラでスキャンしてブックマーク登録が簡単にできる。閉じ方は×ボタン・背景クリック・Escキーの3通り。
UIqrcode.js
⚙️ admin ― メンバー管理
➕
メンバー追加・編集・削除
admin
フォームから名前・YouTube CH ID・各SNS ID・メンバーカラーを入力して追加。メンバー一覧の名前クリックで再編集モードに切り替え。削除は確認ダイアログ付き。
localStorage
🎮
UUID 自動取得（Ashcon API）
admin
Minecraft IDを入力すると700ms debounce後にashcon.app経由でUUIDを自動取得。MojangはCORSブロックのため中継APIを使用。取得成功・失敗・待機状態をバッジで表示。
Ashcon APIUUID
✏️
UUID 手動入力フォールバック
admin
自動取得に失敗した場合、「手動入力」ボタンが出現。ハイフンあり/なし両対応の正規表現バリデーション付き。32文字の場合は自動でハイフン付きに変換。
UUIDバリデーション
🖼️
Minecraftアバタープレビュー
admin
UUID取得後にMineatar（api.mineatar.io）から頭部3D画像をリアルタイムプレビュー。アウターレイヤーも反映。スマホでの外部APIブロック問題を回避するためローカル保存方式を採用。
Mineatar APIスキン
⬇️
アバター SVG ダウンロード
admin
「画像を [マイクラID].svg で保存」ボタンでMineatar画像をBase64エンコードしてSVGラッパーに格納し、ローカルに保存。ファイル名は自動で「{minecraftId}.svg」になる。
SVGダウンロード
📋
config.js 出力＆コピー
admin
メンバー追加・編集するたびにconfig.js形式のコードを自動生成。「コピー」ボタンでクリップボードにコピーし、ローカルのconfig.jsに貼り付けて使う。avatarImgパスも自動補完。
コピー
🎨
メンバーカラー選択
admin
カラーピッカーとHEXコード入力が連動。入力した色はポータル側のメンバー名やアバターボーダーに反映される。明度が高い色は自動で暗色補正してテキストの視認性を確保。
カラーピッカー
📊
メンバー一覧テーブル
admin
登録済みメンバーをカラー・顔アイコン・各SNSリンク付きの横スクロールテーブルで確認。UUIDは先頭8文字を表示しホバーでフル表示（title属性）。
テーブル
🔗 共通 ― データ連携
🔗
config.js 共有データ
index / admin
APIキーとデフォルトメンバー定義を config.js に集約。index・adminどちらもこのファイルを読み込み、localStorageの上書きデータがあればそちらを優先使用する。
localStorage
💡
テキストカラー自動補正
index / admin
adjustColorForText()関数でluma輝度値を計算し、明るすぎる色のメンバー名テキストを自動的に50%暗色化して視認性を確保。
アクセシビリティ
📱
マルチプラットフォーム SNS 対応
index / admin
YouTube / X(Twitter) / Twitch / TikTok / Instagram / Discord の6プラットフォームに対応。各SNS IDの有無でボタンを動的表示。TikTokは@プレフィックスを自動除去。
SNS
🟩
Minecraft アバター表示（SVG）
index / admin
avatars/{minecraftId}.svg を優先参照し、なければ avatars/fallback.svg を表示。onerrorハンドラで読み込み失敗時も自動フォールバック。拡張子の表記ゆれ（png/jpg等）も.svgに正規化。
SVGフォールバック
📐
レスポンシブ対応
index / admin
スマホ（〜599px）・タブレット（600px〜）・PC（950px〜）の3段階でグリッド列数・カードサイズを切り替え。管理画面はスマホで縦積みレイアウトに変形。
レスポンシブ
