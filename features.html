📋 homeクラ 機能一覧

トップページ・拠点マップ・地図の比較・管理画面と、裏側の仕組みの一覧です（2026年11月9日 更新）。

🏠 トップページ（index.html）― 配信の表示
📰
だいたい週刊homeクラNEWS（速報バナー）
index
ナナホシナナさん制作の速報動画を、LIVE中のブロックの上に横長のバナーで出す。表示する回は js/data/news.js で決め、それより新しい「だいたい週刊homeクラNEWS」が出ていれば自動でそちらに替わる。公開から7日で消える。
YouTube API2026-11-09
🔴
homeクラ LIVE中！
index
配信中のうち、配信タイトルに「homeクラ」が入っているものだけを一番上のブロックに出す。「#」の有無・全角・大文字は問わない（#homeクラ も #homeクラ合衆国 も対象）。概要欄は定型文の「homeクラ」で間違えるため見ない。
YouTube API2026-11-08
📡
LIVE中！（homeクラ以外）
index
タイトルに「homeクラ」がない配信は、homeクラ LIVE中！の下の「LIVE中！」ブロックに出す。どちらも0件の時は見出しごと隠す。
YouTube API
🕒
配信予定のメンバー
index
予約枠の開始予定時刻を「🕒 11/9 21:00～」の形で表示。1つのチャンネルが同じ日に2枠以上入れていても全部出す。
YouTube API
🎬
24時間以内の新着（配信アーカイブ）
index
終わった配信のうち、実際に配信を始めた時刻から24時間以内のものを、新しい順に表示。
YouTube API
🆕
2週間以内の新着（動画）
index
配信ではない投稿動画のうち、公開から2週間以内のものを各チャンネル2本まで、新しい順に表示。NEWバッジ付き。
YouTube API
📺
サブチャンネル対応
index
メンバーにサブチャンネルを登録すると、その配信・予定・新着もその人のカードとして出る。メンバー一覧にもサブチャンネルの YouTube ボタンが増える。
config.js の id2
🔤
名前のよみがな
index / PDF
よみがなを登録したメンバーは、配信のカード・メンバー一覧・名簿PDFで名前の上に小さく出す。名前の横幅は広がらない。
UI
👥
メンバー一覧
index
全メンバーを並び順とグループ見出しで並べ、顔アイコン・メンバーカラー・SNSボタン（YouTube / X / Twitch / TikTok / Instagram / Discord / ホームページ）付きで表示。#member で直接移動できる。
UI
🧍
3Dスキン表示
index
メンバー一覧の顔アイコンを押すと、そのメンバーのスキンを3Dで回して見られる。
Minecraft
💬
SNSポップアップ
index
カードの「🔗 詳細」ボタンを押すと、その人のSNSリンクとメンバー一覧への移動ボタンをまとめたポップアップを出す。
UI
📄
メンバー一覧PDF
index
「📄 PDF」ボタンで、顔アイコン・メンバーカラー・SNS・よみがな入りの名簿（members.pdf）を開く。メンバーを変更してコミットすると自動で作り直される。
PDF
📱
QRコード
index
ヘッダーのボタンでトップページのQRコードを表示。パソコンで見ているページをスマホですぐ開ける。
UI
🎰
旬茶作 ルーレット
index
トップページからルーレットのページ（roulette.html）を開ける。
リンク
⚡ 更新の仕組みと YouTube API の節約
🧺
Worker でまとめて取得・みんなで共有
Worker
トップページは Cloudflare Worker に1回聞くだけ。Worker が全メンバー分をまとめて YouTube から取り、10分間保存してみんなで共有するので、見る人が増えても API の使用量は増えない。
10分YouTube API
💾
ブラウザ側の保存
index
取得したデータをブラウザにも5分間保存し、その間に開き直してもすぐ表示する。チャンネルアイコンは24時間保存。取れなかった時は前回のデータで表示する。
5分 / 24時間localStorage
⏱️
10分ごとの自動更新
index
画面上のタイマーで10分ごとに自動更新。ページを見ていない時（別のタブ・離席）は止めて、操作すると再開する。
自動更新
🔄
更新ボタン（強制更新）
index
「更新」ボタンを押すと、ブラウザの保存を使わずに最新データを取り直す。
強制更新
⚠️
表示のタイムラグ
index
保存期間があるため、配信の開始・終了がトップページに出るまで最大20分ほどかかることがある。ロゴの下に注意書きを出している。
仕様

🔔

index

通知

index

🗺️ 拠点マップ（minecraft_map.html）
🗺️
背景地図と配置図
map
取得した日付の名前（例：10月18日）の背景地図を選んで表示。ブロックを積み上げた立体の地図（軽量なWebP）。「配置図」を選ぶと、区画と名前だけの図になる。
Minecraft
🟧
エリア番号で配置
map
赤・オレンジの区画にエリア01〜28の番号があり、エリア番号を書くだけで、その区画の真ん中に顔アイコンが置かれる（座標は自動）。
MAP_member.js
🙂
顔アイコンとネームタグ
map
区画いっぱいの顔アイコンと、名前・座標のネームタグを表示。拡大縮小に合わせて大きさが変わる。
UI
🎛️
地図の表示項目
map
グリッド線・区画の枠線・顔アイコン・名前・座標の表示切り替えと、背景・線・ネームタグの色、ネームタグの背景の濃さ（0〜100%）を変えられる。設定はブラウザに保存。
localStorageUI
📍
目印の場所
map
共有地などの目印を地図の上に表示。
MAP_locations.js
🔍
メンバーへジャンプ・倍率シークバー
map
メンバーを選ぶとその拠点へ移動。倍率は無段階のシークバーで変えられ、「地図全体の表示に戻る」で全体表示に戻る。
UI
📷
スクリーンショット保存
map
今見ている地図を画像で保存。地図の外の黒い所は写さないよう背景地図の範囲で切り抜き、右上に地図の名前、右下にウォーターマークを入れる。
画像保存
🔗
アプリ内ブラウザ対応
map
X などのアプリの中のブラウザ（Android）では画像を保存できないため、案内文と「🔗 URLをコピー」ボタンを出して、Chrome などで開き直してもらう。
Android
📱
スマホ表示
map
スマホでは「設定MENU」とメンバーの引き出しにまとめ、地図を広く使う。上部バーの「🔍 比較」から比較ページへすぐ行ける。

比較

UI

席替え前・後の配置切り替え
比較
左右それぞれの「配置」の選択欄で、今の割り当て（席替え後）と前の割り当て（席替え前）を選べる。顔アイコンも配置図も切り替わる。
2026-11-08

地図ごとの表示項目
比較
グリッド線・区画の枠線・顔アイコン・名前・座標を、左右の地図で別々にオン・オフできる。
localStorage
📷
比較のスクリーンショット
比較
2枚を画面と同じ並びで1枚の画像にする。それぞれの右上に地図の名前と配置（例：10月18日・席替え前）を入れる。
画像保存
⚙️ 管理画面 ― メンバー管理
✏️
メンバー追加・編集・削除
admin
名前・よみがな・チャンネルID・サブチャンネル・Minecraft ID・各SNS・メンバーカラー・並び順・グループを入力して保存。
UI
🆔
UUIDと顔アイコンの取得
admin
Minecraft ID から UUID を自動取得。正面の顔画像（アウターレイヤー込み）をプレビューし、「[マイクラID].png」で保存できる。
Minecraft外部API
🔒
公開・非公開
admin
メンバーごとに公開・非公開をワンクリックで切り替え。非公開のメンバーは GitHub に上げないファイルに分けて保存し、公開ページのソースにも出ない。
非公開
📋
config.js の出力・コピー
admin
編集結果を公開用（js/data/config.js）と非公開用（config.private.js）の形で出力し、コピーして上書き保存する。
config.js
⚠️
保存データの食い違いのお知らせ
admin
ブラウザに残っている編集データが config.js と違う時に、画面の上で知らせる（古いデータで上書きしてしまうのを防ぐ）。
安全
📊
メンバー一覧のCSV出力
admin
メンバー一覧をCSVファイルで書き出す。

🛡️ 裏側の仕組み
🔑
APIキーを隠す
Worker
YouTube の APIキーは Cloudflare Worker の中だけに置き、ページには書かない。許可したサイト以外からの呼び出しは断り、中継する項目も必要なものに絞る。
セキュリティ
📈
アクセス統計
Worker
アクセスを記録し、10分ごとの自動更新と人が開いたアクセスを区別する。関係者のブラウザ（?me=1 で登録、?me=check で確認）や手元のサーバーからのアクセスは除外できる。
統計
🧹
古いファイルが残らない工夫
共通
コミットのたびに、全ページの読み込みファイルに更新番号を付け直し、スマホなどで古いJS・CSSが残らないようにする。
キャッシュ対策
📄
名簿PDFの自動作り直し
共通
メンバーのデータ（js/data/config.js）をコミットする時に members.pdf を自動で作り直し、同じコミットに入れる。
自動
🎨
文字色の自動補正
index
明るすぎるメンバーカラーは、白い背景で読めるよう文字に使う時だけ自動で濃くする。
UI
