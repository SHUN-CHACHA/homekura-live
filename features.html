📋 homeクラ 機能一覧

配信ポータル（index.html）と管理画面（admin）に組み込まれている機能の一覧です。

🏠 index.html ― 配信ポータル（表示系）
🔴
LIVE 中メンバー表示
index
YouTube Live APIでリアルタイムに配信中チャンネルを検出し、サムネ付きカードで最上部に表示。緑ボーダー＋LIVEバッジで強調。
YouTube API
🕒
配信予定（Upcoming）表示
index
liveStreamingDetails の scheduledStartTime を取得し、日時をフォーマットして「配信予定のメンバー」セクションに表示。
YouTube API
🎬
24時間以内の新着動画
index
公開から24時間以内の動画を「新着」として検出し、NEWバッジ付きカードで表示。
YouTube API
👥
メンバー一覧（リスト表示）
index
全メンバーをMinecraftアバター＋SNSアイコンボタン付きでグリッド表示。YouTube / X / Twitch / TikTok / Instagram / Discord / ホームページに対応。アンカーで直接スクロール可能。
UI
🔗
SNS ポップアップモーダル
index
カードの「🔗 詳細」ボタンを押すと、そのメンバーの登録済み SNS リンクをポップアップ表示。YouTube / X / Twitch / TikTok / Instagram / Discord / ホームページを色分けリストで一覧表示。「👥 メンバー一覧へ」ボタンも内包。背景クリック・Escキーで閉じる。
モーダルSNS
👥
一覧ジャンプボタン
index
各カードの「👥 一覧」ボタンを押すと、ページ内の #member（メンバー一覧セクション）へスクロール。SNSポップアップ内の「メンバー一覧へ」も同様。
アンカーリンク
🎲
ルーレットボタン
index
ヘッダー左に配置。外部の旬茶作ルーレットページ（roulette.html）を新しいタブで開くリンク。
UI
⚡ index.html ― API クォータ最適化・キャッシュ
💾
ポータルキャッシュ（5分）
index
動画情報（chInfoMap・vItems）を portal_cache キーで localStorage に保存。5分以内の再ロードは API を叩かずキャッシュを使用。API エラー時も古いキャッシュでフォールバック表示する。有効期間は js/config.js の CACHE_DURATION_MS で変更可能（デフォルト 5 分）。
キャッシュlocalStorageYouTube API
🖼️
チャンネルアイコン長期キャッシュ（24時間）
index
channels API で取得したアイコン URL を channel_icon_cache に保存。24時間以内は channels API を呼ばない。有効期間は js/config.js の CHANNEL_ICON_CACHE_DURATION_MS で変更可能。
キャッシュlocalStorageYouTube API
🔄
強制更新（キャッシュ無視）
index
ヘッダーの「更新」ボタン押下時は loadPortal(true) を呼び、キャッシュを無視して API から最新データを取得・保存し直す。
YouTube API強制更新
📉
playlistItems maxResults=2
index
playlistItems の取得件数を maxResults=2 に設定。LIVE / Upcoming 優先ロジック（先頭2件からステータス付き動画を優先）を維持しつつ、不要な取得を削減。
YouTube API
🔔 index.html ― 通知・予約
🔔
配信開始 通知予約
index
Upcoming動画に「🔔 通知予約」ボタンを表示。予約するとブラウザ通知の許可を求め、開始時刻に「配信開始！」をプッシュ通知。予約状態はlocalStorageに保存。
通知APIlocalStorage
✅
通知状態の永続化
index
通知済みかどうかを notified フラグでlocalStorageに管理。30秒ごとにポーリングして重複通知を防ぐ。
localStorage
📱 index.html ― スマホ連携
📱
QRコード モーダル
index
ヘッダーの「QR」ボタンを押すと現在URLのQRコードをモーダル表示。スマホカメラでスキャンしてブックマーク登録が簡単にできる。閉じ方は×ボタン・背景クリック・Escキーの3通り。
UIqrious.js
⚙️ admin ― メンバー管理
➕
メンバー追加・編集・削除
admin
フォームから名前・YouTube CH ID・各SNS ID・ホームページURL・メンバーカラーを入力して追加。メンバー一覧の名前クリックで再編集モードに切り替え。削除は確認ダイアログ付き。
localStorage
🏠
ホームページURL 登録
admin
メンバーごとにホームページURLを登録可能。登録するとポータルの SNS ポップアップモーダルに「ホームページ」リンクとして表示される。未登録の場合は非表示。
SNS
🎮
UUID 自動取得（Ashcon API）
admin
Minecraft IDを入力すると700ms debounce後にashcon.app経由でUUIDを自動取得。MojangはCORSブロックのため中継APIを使用。取得成功・失敗・待機状態をバッジで表示。
Ashcon APIUUID
✏️
UUID 手動入力フォールバック
admin
自動取得に失敗した場合、「手動入力」ボタンが出現。ハイフンあり/なし両対応の正規表現バリデーション付き。32文字の場合は自動でハイフン付きに変換。
UUIDバリデーション
🖼️
Minecraftアバタープレビュー
admin
UUID取得後にMineatar（api.mineatar.io）から頭部3D画像をリアルタイムプレビュー。アウターレイヤーも反映。スマホでの外部APIブロック問題を回避するためローカル保存方式を採用。
Mineatar APIスキン
⬇️
アバター SVG ダウンロード
admin
「画像を [マイクラID].svg で保存」ボタンでMineatar画像をBase64エンコードしてSVGラッパーに格納し、ローカルに保存。ファイル名は自動で「{minecraftId}.svg」になる。
SVGダウンロード
📋
js/config.js 出力・コピー（window.CONFIG 形式）
admin
メンバー追加・編集するたびに window.CONFIG = {...} 形式のコードを自動生成。APIキー・キャッシュ設定値（CACHE_DURATION_MS・CHANNEL_ICON_CACHE_DURATION_MS）・homepageUrl も含めて出力。「コピー」でクリップボードにコピーしてローカルの js/config.js に貼り付けて使う。
コピー
🎨
メンバーカラー選択
admin
カラーピッカーとHEXコード入力が連動。入力した色はポータル側のメンバー名やアバターボーダーに反映される。明度が高い色は自動で暗色補正してテキストの視認性を確保。
カラーピッカー
📊
メンバー一覧テーブル
admin
登録済みメンバーをカラー・顔アイコン・各SNSリンク・ホームページリンク付きの横スクロールテーブルで確認。UUIDは先頭8文字を表示しホバーでフル表示（title属性）。
テーブル
🔗 共通 ― データ連携
🔗
js/config.js 共有データ
index / admin
APIキー・キャッシュ設定・デフォルトメンバー定義を window.CONFIG として js/config.js に集約。index・admin どちらもこのファイルを読み込み、localStorage の上書きデータがあればそちらを優先使用する。
localStorage
💡
テキストカラー自動補正
index / admin
adjustColorForText() 関数で luma 輝度値を計算し、明るすぎる色のメンバー名テキストを自動的に50%暗色化して視認性を確保。
アクセシビリティ
📱
マルチプラットフォーム SNS 対応
index / admin
YouTube / X(Twitter) / Twitch / TikTok / Instagram / Discord / ホームページの7プラットフォームに対応。各 SNS ID・URL の有無でリンクを動的表示。TikTok は @ プレフィックスを自動除去。
SNS
🟩
Minecraft アバター表示（SVG）
index / admin
avatars/{minecraftId}.svg を優先参照し、なければ avatars/fallback.svg を表示。onerror ハンドラで読み込み失敗時も自動フォールバック。拡張子の表記ゆれ（png/jpg等）も .svg に正規化。
SVGフォールバック
📐
レスポンシブ対応
index / admin
スマホ（〜599px）・タブレット（600px〜）・PC（950px〜）の3段階でグリッド列数・カードサイズを切り替え。管理画面はスマホで縦積みレイアウトに変形。
