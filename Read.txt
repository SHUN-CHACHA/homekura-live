【各ファイルの役割】
--------------------------------------------------------------------

■ minecraft_map.html
    メンバーの拠点位置を示すマップ本体。ブラウザでこのファイルを
    ダブルクリックすれば、そのまま動作します（サーバー不要）。
    地図の見た目・レイアウト・スマホ対応などのロジックはすべて
    このファイルの中に書かれています。

■ js/MAP_member.js
    メンバーの一覧データだけをまとめた設定ファイル。
    メンバーの追加・変更・削除はこのファイルだけを編集すれば反映されます。
    minecraft_map.html から <script src="js/MAP_member.js"> で読み込まれます。

    【1人分のデータの書き方】
      { area: "エリア01", name: "名前", icon: "ファイル名.svg",
        name2: "", icon2: "", x: 720, z: 0 },

      area   … 表示用のエリア名（未使用でも空文字でOK）
      name   … メンバー名
      icon   … avatars フォルダ内の顔画像ファイル名
      name2  … 同じ拠点に2人目がいる場合の名前（いなければ空文字）
      icon2  … 2人目の顔画像ファイル名（いなければ空文字）
      x, z   … マイクラのワールド座標

      ※ name が空文字の行は「未登録枠」として地図にも一覧にも表示されません。

■ background_image_guide.html
    world_map.png（地形の背景画像）をChunkbaseから作成する手順の説明ページ。
    minecraft_map.html の「背景画像の設定ガイド」ボタンから開けます。

■ world_map.png
    地図の背景として表示する地形画像（Chunkbaseで作成したもの）。

■ avatars/
    メンバーの顔アイコン画像を入れるフォルダ。
    js/MAP_member.js の icon / icon2 で指定したファイル名がここに
    存在しない場合は、グレーのプレースホルダー画像が代わりに表示されます。
