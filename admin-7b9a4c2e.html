🎨 顔アイコン（アバター）の追加手順

  1. 画像を準備する
    • 下部のメンバー一覧から名前をクリックしてデータを参照するか、新規に必要項目を記入します。
    • Minecraft ID を入力すると、Ashcon API 経由でUUIDを自動取得します（Mojang APIはブラウザから直接呼べないためCORS対応プロキシを使用）。
    • UUIDが取得できると Mineatar（api.mineatar.io）で頭部3D画像がプレビュー表示されます。アウターレイヤーも正確に反映されます。ナナちゃんのハゲを隠すのにここまでしないと駄目でした
    • 「画像を【Minecraft ID】.svg でPCに保存」ボタンをクリックするとダウンロードフォルダに画像が保存されます。
    • 編集が完了したら「メンバーを保存」ボタンをクリックしてください。UUIDも一緒に保存されます。
  2. 画像ファイルのアップロード
    • ルートディレクトリに avatars フォルダを作成します。
    • ダウンロードした画像ファイルをその avatars フォルダ内に保存します。
    • 画像がない・まだ用意していないメンバーは、自動的に avatars/fallback.svg が表示されます。
  3. 画像ファイルの紐づけ
    • 「⚙️ config.jsの書き換え」から「config.jsの内容をコピー」ボタンをクリックするとクリップボードにコピーされます。
    • コピーした内容をWEBの js/config.js に全文貼り替えて保存してください。
    • アップロードが完了したら反映されているか確認して終了です。

※ UUID取得について：Mojang APIはブラウザからの直接アクセスがCORSでブロックされるため、CORS対応の api.ashcon.app を経由してUUIDを取得しています。取得したUUIDはjs/config.jsに保存されます。
※ 画像はMineatar（api.mineatar.io）から取得しローカルに保存することで、スマホ表示時の外部APIブロック問題を回避しています。

📝 使い方メモ

  • 「登録メンバーから選択」で上の👥 メンバー追加・編集に登録済みの人を選ぶと、名前・アイコンが自動入力されます（表記ゆれ防止のため、名簿にいる人はできるだけこちらから選んでください）。
  • 名簿にいない人（配信者ではない参加者など）は自由入力欄に直接入力してください。
  • アイコン画像ファイルは avatars フォルダに置く前提です。上の「👥 メンバー追加・編集」でアバターをダウンロードしてから使うと簡単です。
  • 座標（X・Z）はマイクラの F3 画面で確認した数値をそのまま入力してください。
  • 1つの拠点に最大3人まで登録できます。空欄のままでもOKです。

🖼️ 背景地図 編集（map-config.js）

✏️ 背景地図編集モード中

⚙️ map-config.js の書き換え

この出力は配列部分だけです。ファイルまるごとの置き換えではありません。js/map-config.js を開き、const mapImageList = [ ... ]; の部分だけを、下のコードで置き換えて保存してください（前後の関数コードはそのままにしてください）。

js/map-config.js を直接手入力で編集した場合は、下のボタンでこのページのデータを最新の内容に合わせ直してください（このブラウザに保存されている編集中のデータは破棄されます）。

📝 使い方メモ

  • 新しい月の地図画像は、まず画像ファイル本体を map フォルダにアップロードしてください（この管理画面からは画像ファイル自体はアップロードできません）。
  • 「画像ファイル名」は map/ を付けずに入力してください（自動で付きます）。
  • 座標は Chunkbase などで切り抜いた画像の範囲（左上と右下の2点、X・Z座標）を入力してください。
  • 新規に保存した地図は一覧の先頭に追加されます（先頭＝サイトを開いた時に最初に表示される地図になります）。順番を変えたい時は一覧の▲▼ボタンで並べ替えてください。
