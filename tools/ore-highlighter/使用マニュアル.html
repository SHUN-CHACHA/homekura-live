1. これは何か

Minecraftの採掘中に、ダイヤ鉱石などの対象ブロックを視認しやすくするためのリソースパック生成ツールです。 ブロックのテクスチャに「レインボー」「枠線」「点滅」などのアニメーション効果を付けたリソースパックを、 プログラミング不要・GUI操作だけで作成できます。あわせて、体力・満腹度ゲージのアイコンをドット絵で 自由に描き替える機能も搭載しています。

2. 起動方法

配布用の .exe 版がある場合は、以下の手順は不要でダブルクリックだけで起動できます。

① Python 3.10以降をインストール（python.orgから入手可能）
② 必要なライブラリを一度だけインストール
pip install PyQt6 Pillow
③ main.py・gui_icon_editor.py・texture_effects.py・texture_names.py を同じフォルダに置く
④ そのフォルダで python main.py を実行

3. ブロックエフェクトタブ

画面は左から「テクスチャ一覧」「対象ブロック」「編集エリア」の3列構成です。

3-1. テクスチャの読み込み

「フォルダを開く...」（展開済みのテクスチャフォルダを選ぶ場合）または 「jarから読み込む...」（26.2.jarやclient.jarを直接選ぶ場合）で読み込みます。 jarを指定した場合は、中の assets/minecraft/textures/block 以下のPNGが自動で取り出されます。

検索ボックスにキーワード（例: diamond）を入れると絞り込めます。 一覧から加工したいブロックを選び、「→ 対象ブロックに追加」で中央の「対象ブロック」一覧へ追加します。 複数選択して一括追加することもできます。

3-2. ディレクトリの指定方法（jarの場所が分からないとき）

「26.2.jarがどこにあるか分からない」という場合のために、 「ランチャーのルートフォルダから探す...」ボタンを用意しています。 公式ランチャーまたはPrism Launcherのルートフォルダを指定するだけで、 中にあるバージョンjarを自動でスキャンし、プルダウンに一覧表示します。

指定するフォルダは、以下のどれでも構いません（ツールが自動で判別します）。

指定するフォルダWindowsでの目安の場所
公式ランチャーの .minecraft フォルダそのもの %appdata%\.minecraft
Prism Launcher のルートフォルダ（中にinstancesフォルダがある場所） %appdata%\PrismLauncher
Prism Launcher の特定インスタンスのminecraft（または.minecraft）フォルダ %appdata%\PrismLauncher\instances\（インスタンス名）\minecraft
Prism Launcherのルートフォルダを指定した場合は、全インスタンスをまとめてスキャンし、 「インスタンス名 / バージョン名」の形でプルダウンに一覧表示されるので、 インスタンスを新しく作り直した後でも同じ手順で見つけられます。

プルダウンから見つかったバージョンを選ぶと、そのjarが自動で読み込まれます （手動で「jarから読み込む...」を選んでファイルを指定したのと同じ結果になります）。 見つからなかった場合はエラーにはならず、案内メッセージが表示されるだけなので、 その場合は今まで通り「フォルダを開く...」または「jarから読み込む...」で直接指定してください。

3-3. ブロックごとのエフェクト設定

中央の「対象ブロック」一覧からブロックを選ぶと、右側にそのブロック専用のエフェクト設定が表示されます。 ブロックごとに完全に別々の設定を持てるので、「ダイヤはレインボー、怪しい砂利は点滅」のような 使い分けが可能です。中央の一覧で複数選択した状態でパラメータを変更すると、選択した全ブロックに一括反映されます。

エフェクト内容主なパラメータ
レインボー + 枠線色相を回転させながら、縁を虹色で縁取るフレーム数／表示時間／枠太さ／枠の彩度・明度
レインボーのみブロック全体の色相を回転させるフレーム数／表示時間
枠線のみ縁を指定色で縁取り、点滅させる枠太さ／表示時間
点滅明るい状態⇔暗い状態を切り替える表示時間／暗さ（dark_factor）

「選択中のブロックをプレビュー」ボタンで、設定した見た目をその場でアニメーションGIFとして確認できます。

3-4. 出力設定

パック名・説明文を指定し、出力先フォルダを決めます。 「Prism Launcherのインスタンスを検出」ボタンを押すと、PC内のPrism Launcherインスタンスを自動で 探して一覧表示し、選ぶだけで resourcepacks フォルダが出力先に設定されます。 見つからない場合は「参照...」から手動で選択してください。

出力先フォルダの中に、指定したパック名のフォルダがそのまま作られます（zip化はされません）。 同名のパックが既にある場合は上書きされます。

3-5. 生成

「リソースパックを生成」を押すと、中央の「対象ブロック」一覧にある全ブロックが、それぞれの 個別設定でパックに書き出されます。生成後、Minecraft側でリソースパックを有効化すれば反映されます。

4. GUIアイコン編集タブ（体力・満腹度）

体力（heart）49種・満腹度（food）6種の状態（バリアント）ごとに、9×9ドットの絵を描いて 差し替えられます。左の一覧から編集したい状態を選び、中央のキャンバスで描きます。

4-1. 描画ツール

左クリック＝描画、右クリック＝消去という操作ルールは、ペン・バケツどちらのツールでも共通です。

4-2. 色の選択

4-3. キャンバスと1ドット移動

画面外にはみ出た部分は消え、反対側は透明になります。細かい位置調整をしたいときに使ってください。

4-4. 保存する・元に戻す

描画・消去・移動などの操作は、「保存する」ボタンを押すまでは下書き（未保存）の状態です。 一覧の●マークや、生成されるリソースパックには反映されません。

未保存の状態のまま「別の状態を選ぶ」「ブロックエフェクトタブに切り替える」「アプリを終了する」のいずれかを 行おうとすると、確認ダイアログが表示されます。「保存」で確定、「破棄」で編集前の状態に戻す （＝元に戻すボタンと同じ動作）、「キャンセル」でその場に留まれます。

4-5. オリジナル（本物）アイコンの参照

バリアントを選ぶと、キャンバスの下に本物のバニラアイコンが表示され、見比べながら描けます。 jarから読み込んだ場合は自動で参照されますが、フォルダを直接指定した場合は 「参照元フォルダを開く...」ボタンで .../gui/sprites/hud フォルダを指定してください。 一度指定した参照元フォルダは次回起動時にも自動的に復元されます（フォルダが存在しない場合は無視されます）。

体力・満腹度のHUDアイコンは、Minecraft起動時に一度だけ読み込まれてキャッシュされます。 リソースパックを無効化→再有効化しただけでは変更が反映されないので、確認するには ゲームを完全に再起動してください（ブロックテクスチャとは挙動が異なります）。

5. 設定の保存・読み込み

アプリを終了するたびに、現在の設定（読み込みフォルダ・対象ブロック一覧・出力先・パック名・ GUIアイコンの編集内容など）が自動的に config.json（main.pyと同じ場所）に 保存され、次回起動時に自動で読み込まれます。

「設定を保存」「設定を読み込み」ボタンを使うと、別名で設定ファイルを書き出したり、 複数のプリセットを切り替えて使ったりできます。

6. 既知の制約・トラブルシューティング

症状・制約説明・対処
「点滅」エフェクトのコマ数現バージョンでは2コマ固定です。
HUDアイコンが変わらないゲームの完全再起動が必要です（4-5節を参照）。
一覧の日本語名が「―」と出るそのファイル名がまだ辞書に未収録なだけで、機能には影響ありません。よく使うブロックが未収録の場合はご連絡ください。
バリアント間の複製現バージョンでは簡易的な仕組みのため、同じ絵を複数バリアントで使いたい場合は外部PNGインポートで代用してください。
