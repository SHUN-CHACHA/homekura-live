背景地形画像の作成ガイド

🗺️ 拠点マップへ戻る

Chunkbase Seed Mapを使って、UIノイズ（グリッド線・アイコン・マーカー）のないクリーンな地形画像を作成する手順です。X=0, Z=0 を中心とした ±1500 ブロックの範囲を撮影します。

1 初期設定

  1. Chunkbase Seed Map を開く
  2. homeクラのシード値を入力する
  3. Version: Java 26.2（Chaos Cubed）を選択
  4. Dimension: Overworld

2 ノイズ要素を消す

  • Features（構造物アイコン）ボックスを展開 → 全項目のチェックを外す
  • ⚙️設定メニューを開く
    • Grid Lines（グリッド線）→ オフ
    • Coordinate labels（座標ラベル）→ オフ（あれば）
    • Slime chunks 表示 → オフ
  • 右クリックで作成したカスタムマーカーが残っていれば削除

3 全画面表示にする

マップをクリックしてキーボード操作を有効化した後、T キー（または右上の拡大ボタン）で地図を画面いっぱいに表示します。ブラウザの余白やサイドバーが写り込まなくなります。

4 中心座標とズームを合わせる

  • 座標入力欄に X: 0, Z: 0 を入力してジャンプ
  • 画面の四隅がだいたい ±1500 になるようズームを調整
  • ズームは基本的に2倍刻みのため、ぴったり合わせるのは難しい → 気持ち広め（±1600〜1700程度）に撮っておき、後でトリミングするのが確実

5 スクリーンショットを撮る

  • Windows: Win + Shift + S
  • Mac: Cmd + Shift + 4
  • 地図部分だけを範囲選択（アドレスバーやタブは写り込ませない）

6 正方形にトリミング

無料の画像編集ツール（Photopea がPhotoshop感覚で使いやすくおすすめ）で開き、中心（X:0, Z:0）を基準に上下左右が対称になるよう正方形にクロップします。

完成したら world_map.png として保存してください。

位置合わせのヒント

座標メモが最も重要です。「画像の上端がZ座標いくつか」「左端がX座標いくつか」をChunkbaseのグリッド上で確認して、minecraft_map.html の bounds 設定に正確に入力してください。
